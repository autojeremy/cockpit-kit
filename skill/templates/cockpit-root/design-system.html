Cockpit/Design System

Design System

User-owned visual register for Cockpit Kit starter pages.

The starter follows the Cockpit baseline: console mono body, a gray canvas, thin rule borders, a restrained green accent, and a sticky left navigation rail with search in the top-left corner. It ships a light and a dark palette; the compact theme switcher in the top-right corner picks Light, Dark, or System (follow the operating system).

Color

Chips render the active palette through var(--token); switch the theme to compare. Pages must use these tokens, never literal colors, so every page follows the theme.

Theme

cockpit-theme.js loads in <head> and sets <html data-theme> to system, light, or dark before first paint. The choice is stored in localStorage under cockpit-theme. Without JavaScript the page follows prefers-color-scheme and the switcher stays hidden. The switcher is a radio group of three icon buttons (half circle = System, sun = Light, moon = Dark) fixed to the top-right corner inside the safe-area insets; while it is visible, --cockpit-top-reserve and --cockpit-right-reserve hold the space it needs.
